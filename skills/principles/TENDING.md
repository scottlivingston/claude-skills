# Tending a PRINCIPLES.md

The checks `/tend` runs on a `PRINCIPLES.md`, against what [SKILL.md](SKILL.md) says the file is for. The file is the human's (SKILL.md, *Changing a principle*), so every finding here — `/cold-read`'s defects included — is a question carrying its drafted edit and proof, never an edit.

- **Unquotable principle** — one a decision couldn't cite, because no agent could tell whether a candidate honours it. Draft: a sharper statement of what it seems to prefer.
- **Bare reference solution** — a system named without what to take from it. Draft: the take, from where the repo already resembles it.
- **Unsettled addition** — an entry whose commit or surrounding text quotes no human answer that settled it. Proof: the line's history. Draft: keep it, or strike it.
- **Misfiled entry** — a rule checkable against a diff (`CONVENTIONS.md`) or a term's definition (`CONTEXT.md`). Draft: the move.
- **Copy, not delta** — a scoped file restating a root principle unchanged. Proof: the root text. Draft: strike the copy.
